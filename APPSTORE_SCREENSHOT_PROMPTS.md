## How to use these four prompts

**Attach the approved Rooms image alongside the prompt.** Every prompt below is written to say "match the attached exactly, change only the headline and the screen contents." Without the attachment they will drift.

Works in ChatGPT / GPT Image and Google Gemini (Nano Banana), both of which take an image plus text.

Locked-in decisions from the approved panel:
- App content fills only the **top two thirds** of the phone screen, empty dark below
- **No readable words inside the phone.** Names and labels are neutral grey placeholder bars. Numbers, percentages and icons are fine
- Characters appear in Rooms and Progress only

## Fixes if something drifts

**Arabic wrong:**
```
The Arabic is incorrect. Regenerate the image identically, changing only the Arabic headline. It must read exactly this, in connected cursive Arabic script, right-to-left, with all letters joined:
<paste the Arabic line>
Keep everything else exactly the same.
```

**Phone moved or resized:**
```
The phone is not positioned the same as the attached reference. Regenerate with the phone at the identical size, identical horizontal centering, and identical vertical position and bottom crop as the attached image. Keep everything else the same.
```

**Shadda on لوّن:** if the mark above the waw renders as a floating artifact, drop it and use `لون حياتك`. Still reads correctly in context.
