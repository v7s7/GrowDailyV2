How it gets built

Small and pure. The world is worked out from what the app already keeps, the same way on every phone, so it can never drift or be backdated. One new number is stored. Nothing is built until you pick a direction and say yes.

The rules, as pure functions

/// lib/features/doum_world/world_model.dart WorldItems itemsFor(int worldLevel); // one per level to 35, then the tree List<Bloom> bloomsFor(Set<String> medalIds); // family picks the kind int weeksFor(List<MilestoneEvent> events); // streak hit 7, 14, 21... int thirstFor(List<OwedDay> days, DateTime now); int thirstFor(days, now) { // newest first; today is never judged against you var thirst = 0; for (final d in days.where((d) => !d.isToday(now))) { if (d.isYesterday(now) && now.hour < kDayCutoffHour) continue; if (d.owedCount == 0 || d.allResting || d.paused || d.coveredByFreeze) continue; // never counts if (d.doneCount > 0) break; // watered if (++thirst == 3) break; // the most it gets } return days.any((d) => d.isToday(now) && d.doneCount > 0) ? 0 : thirst; // one square today }

What I need from you, in order

  1. The direction: A planet, B tree, C palm, D farm, E Doum grows, or F Doum farms his planet.
  2. Quiet days: yes or no to the world getting gently thirsty (it bends rule 2 for the world only).
  3. The name, and whether reminders stay inside the app at launch.
  4. Generate the sheets for that direction from the Art board. Sheet D (Doum at work) is worth doing whichever you pick.
  5. Then I build wave 1 with tests, on a branch, and show it to you on the simulator before anything ships.
