Yellow, or the done colour?
Same half fill either way. The only question is whether the filled half borrows the "done" colour or keeps the warning yellow that already means "not all the way" everywhere else in the app.

One more reason, and it is not aesthetic
A partial square pays 5 XP where a done square pays 10 (SquareState.xpValue). A mark that wears the done colour but pays half is telling the person something untrue about their own week. Yellow keeps the colour honest about the payout.
And colour is the only signal that survives a colour-blind viewer badly, so the half height is the redundant encoding for them. Keeping both means neither has to work alone.
